## 三、G1.3 / G1.4 — 逐项修复

`d105fab` 中批量处理。逐 lint 类别说明:

### 3.1 机械 in-tree 修复(~40 sites)

| 类别 | 修复 |
|---|---|
| `useless_format` × 3 | `format!("X")` → `"X".to_string()` |
| `len_zero` × 4 | `args.len() != 0` → `!args.is_empty()`,`args.len() < 1` → `args.is_empty()` |
| `single_char_add_str` × 2 | `out.push_str("\n")` → `out.push('\n')` |
| `manual_pattern_char_comparison` × 1 | `|c\| c == '\n' \|\| c == '\r'` → `['\n', '\r']` |
| `manual_repeat_n` × 1 | `std::iter::repeat(c).take(n)` → `std::iter::repeat_n(c, n)` |
| `useless_vec` 等 | cargo fmt 自动处理 |
| `let_and_return` × 1 | 直接返回 match 表达式,去除 `let x = match ...; x` |
| `needless_return` × 2 | `return Err(...)` → `Err(...)`(match arm 末表达式) |
| `question_mark` × 1 | `let outcome = match result { Ok(o) => o, Err(e) => return Err(e) };` → `result?` + `let outcome = result;` |
| `infallible_destructuring_match` × 2 | `let mut d = match e { Diagnostic(d) => d };` → `let Diagnostic(mut d) = e;` |
| `needless_borrow` × 2 | `&dir.join("e.txt")` → `dir.join("e.txt")`(dir: PathBuf,joint 返回 PathBuf) |
| `needless_borrows_for_generic_args` × 1 | `std::fs::write(&dir.join(...), b"x")` → `std::fs::write(dir.join(...), b"x")` |
| `unnecessary_sort_by` × 1 | `sort_by(|a,b\| a.0.display().cmp(&b.0.display()))` → `sort_by_key(|a\| a.0.display())` |
| `needless_lifetimes` × 1 | `pub fn resolve_namespace<'a>(...)` → `pub fn resolve_namespace(...)` |
| `explicit_counter_loop` × 1 | `for fe in child_edges(e) { ... }` + `sibling += 1;` → `for (sibling, fe) in child_edges(e).into_iter().enumerate() { ... }` |
| `borrowed_box` × 1 | `#[allow(clippy::borrowed_box)]` 标注 + 注释(签名被 5 个 caller 通过 `.as_ref()` 使用;重构成 `&Expr` 会破坏 API) |

### 3.2 file-level allow(项目风格选择)

| 类别 | 处理 |
|---|---|
| `doc_overindented_list_items` × 13 | `#![allow(clippy::doc_overindented_list_items)]` 在 `wlwl-eval/src/lib.rs` + `wlwl-lexer/src/lib.rs` 顶部。项目风格:bullet 续行的缩进对齐到 bullet 文本的列号,不是 4 spaces。rationale: P4-G1-003 |

### 3.3 局部 allow(rationale 必须明确)

| 类别 | 站点 | 决策 |
|---|---|---|
| `result_unit_err` | `wlwl-eval/src/lib.rs:300` `set_cell_value` | 三态返回 `Ok(found_immutable)` / `Ok(false)` / `Err(not_found)`。改成 `Result<bool, SomeError>` 需新增错误类型且不影响 caller。P4-G1-004 |
| `approx_constant` × 3 | `serde_roundtrip.rs:70`(3.14159 literal 数据);`lib.rs:11695`(`FLOAT("3.14")` 解析测试);`lib.rs:12954`(`NEG(3.14)` 测试) | 这些是**测试数据**,不是 π 近似。改用 `std::f64::consts::PI` 会改变测试语义。P4-G1-005 |
| `dead_code` × 2 | `trace_call_uses_call_site_identifier`(Phase A1d 改写后的遗留测试);`expect_dict`(为 §12.6 ERR consumer 集成预留的 helper) | 标注 `#[allow(dead_code)]` + rationale。P4-G1-006 |
| `non_snake_case` | `INDEX_GET`(`wlwl-eval/src/lib.rs:11626`) | 函数名匹配 spec §10.1 全局 builtin registry 的 "INDEX_GET"(附录 G 锁定)。改成 `index_get` 会破坏 builtin dispatch。P4-G1-007 |
