# 2026-09-15 (续B1) — INDEX_GET / INDEX_SET / AT / REMOVE_KEY / POP (spec v0.4 §10.1 / §10.2)

A8 (commit 79a9fb7) 把 Phase A 全部收尾后接 Phase B 入口 B1。spec v0.4
§10.1 / §10.2 把 v0.3 缺失的"下标访问"原语补齐:数组支持负数索引、
字典支持 INDEX_GET / SET、3 个 lenient 接口(`AT` / `REMOVE_KEY` /
`POP`(dict 版))。本批 0 行 lexer/parser 改动 (语法糖 `arr[i]`,
`arr[i] = v`, `d[k]`, `d[k] = v` 留 Phase E2 单独 PR), 5 个新 builtin
+ 2 个新错误码 `E0036` / `E0037` + 30 个新测试。Phase B 入口开张。

## 范围 (spec v0.4 §10.1 / §10.2)

| 函数 | 签名 | 语义 |
|------|------|------|
| `INDEX_GET(arr, i)` | INTEGER index (支持负数) | `-LEN ≤ i < LEN`; OOB → `E0036` |
| `INDEX_GET(d, k)` | 任意 key | 缺键 → `E0037` |
| `INDEX_SET(arr, i, v)` | INTEGER index | 同上; return 新 array |
| `INDEX_SET(d, k, v)` | 任意 key | upsert; 保留插入顺序 |
| `AT(arr, i, default)` | lenient INDEX_GET | OOB → default, **不抛** |
| `AT(d, k, default)` | lenient INDEX_GET | 缺键 → default, **不抛** |
| `REMOVE_KEY(d, k)` | 主推名 (v0.4 重命名) | 缺键 NOOP; return 新 dict |
| `POP(d, k, default)` | 安全删除 | 键存在 → 返回值 + 移除; 缺键 → default |

新错误码:
- `E0036` — array index out of bounds (Type bucket)
- `E0037` — dict key not found (Type bucket)

非 INTEGER index → `E0031` (沿用现有 subscript-type 错误码;不是新码)。

## 关键设计决策

1. **5 个新 builtin 都不进 §12.7 ERR 消费者注册表**:沿用 §12.6 默认 ERR
   透明传播。`eval_call` line 1935-1944 的 `is_err_consumer` 短路路径自动
   处理 (5 个测试 `index_get_propagates_err` / `index_set_propagates_err` /
   `at_propagates_err` / `remove_key_propagates_err` / `pop_dict_propagates_err`
   锁定该行为)。
2. **`POP` 仅为字典版**:spec v0.3 §10.1 列 `POP(arr)` 移除末尾元素; plan
   B1 任务限定为 DICT 版 (`POP(d, k, default)`)。`POP(arr)` 留 v0.5
   (deviations B1-002)。
3. **错误码选择**:非 INTEGER array index → `E0031` (subscript-type 专用) 而非
   `E0030` (generic type error)。`resolve_array_index` helper 用 `builtin_error`
   直接发 `E0031`。
4. **3 个 helper**:`resolve_array_index` (INTEGER 校验 + 范围检查 + 负数
   normalise) / `dict_lookup` (entries.iter().position via `values_equal`)
   — 让 INDEX_GET / INDEX_SET / AT 三者共用同一原语,避免代码重复。
5. **"原地"语义 emulated by clone-mutate-return**:tree-walking 解释器下
   `Value::Array` / `Value::Dict` 是 owned `Vec`,无 `Rc<RefCell<_>>` 共享。
   `INDEX_SET(arr, i, v)` / `REMOVE_KEY(d, k)` clone 容器 + 修改 clone +
   返回 clone — 用户视角等价 (无别名)。后续 Phase 如引入 aliasing 可改为
   原地 (deviations B1-003)。
6. **`POP` 返回的是被删值,不是修改后的 dict**:spec §10.2 row "安全删除"
   说"返回删除的值"。`pop_dict_existing_returns_value_and_removes` 测试用
   `POP(["a":1, "b":2], "a", NULL) → 1` 锁定该语义。
7. **字典插入顺序保留**:`INDEX_SET(d, k, v)` upsert:已存在 key → 保持原位;
   新 key → push 到末尾 (与 `MERGE` 行为一致; §10.2 row 6)。
8. **parser 端 `arr[i]` / `d[k]` 语法糖 留 Phase E2**:plan v0.2 §3 B1 任务
   "1.5 天"含语法糖,本批**不实现** 语法糖 (避免单 PR 范围过大),由后续
   batch 单独 PR (deviations B1-004)。函数形式已足够覆盖测试与运行期使用。
