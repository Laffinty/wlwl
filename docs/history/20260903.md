## 收尾五: P3-010 — 修 parse_type_expr_from_pieces 错误吞咽 bug (同日续五)

### 1. bug 出处

P3-009f 加 3 个 *_swallowed tripwire 测试时, 发现 parse_type_expr_from_pieces 里 let expr = p.parse_expr(sl, sc); 没用 ?. parse_expr 错误被静默丢进 leftover arm, 总是返回 Ok(TypeExpr::Generic { ... }). 3 个测试靠加 _swallowed 后缀才 过 (实际是错的行为, 测试在断言 buggy 行为). 标 P3-010 (1.x 范围).

### 2. impl fix: 改用 ? 传播

- impl/crates/wlwl-parser/src/lib.rs 行 1102-1105: 1 行 let expr = p.parse_expr(sl, sc); → let expr = p.parse_expr(sl, sc)?;, 末尾 expr 改为 Ok(expr).
- 3 个 *_swallowed 测试改名为 *_errors_with_eNNNN, 反映错误正确传播而非我们保留吞咽行为:
  - parse_type_pieces_paren_block_is_swallowed → parse_type_pieces_paren_block_errors_with_e0010
  - parse_type_pieces_unclosed_array_is_swallowed → parse_type_pieces_unclosed_array_errors_with_e0012
  - parse_type_pieces_keyword_in_array_is_swallowed → parse_type_pieces_keyword_in_array_errors_with_e0010

### 3. 行为变更 (3 个之前 silently 返回 Generic 的错误输入)

| 输入 | 旧行为 (bug) | 新行为 |
