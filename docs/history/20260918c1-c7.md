## C2:MODULE_REF + GET_PROP / SET_PROP / CALL_METHOD(spec §13.12 / §5.5 / §8.6)

B15 留下的 4 个 placeholder 全部替换:

- `MODULE_REF(path) -> DICT`:加载模块但不绑定名字,返回 EXPORT 面的
  DICT(键字典序)。与 IMPORT 共用 ModuleLoader(缓存 / 循环检测 /
  命名空间解析 / E0040 边界),加载失败原样冒泡。
- `GET_PROP(d, k)`:DICT 属性读,缺键 E0037;`SET_PROP(d, k, v)`:插入 /
  更新,返回新 DICT(值语义,与 INDEX_SET 一致,P4-C2-002)。
- `CALL_METHOD(d, m, args...)`:查成员并调用。self 注入规则(P4-C2-001):
  closure 仅当首形参名为 `self` 时注入 receiver(§8.6 主句 + §5.5 关键
  决策);NativeFn(std 模块成员)不注入(§13.12:`io.PRINT("hi")` 等价
  `IMPORT` 后 `PRINT("hi")`)。

`d.f(x)` 语法糖(parser 早已脱糖到 GET_PROP / CALL_METHOD)因此对普通
DICT 和模块对象都可用。
