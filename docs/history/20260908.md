## 范围（spec v0.4 §7.5）

`LET` 的第一参数支持解构模式。模式复用 ARRAY / DICT 字面量形态：
- 数组：`[a, b]` / `[head, *rest]` / `[_, mid, _]`
- 字典：`["x": x, "y": y]` / `["name": n]`
- 嵌套：`[[a, b], [c, d]]` / `["user": ["name": n]]`
- 规则：必须完全匹配 → E0026；`_` 占位；`*rest` 收集剩余元素为 ARRAY；
  **不支持** 默认值（v0.5 议程）
- 解构不是新表达式；是 LET 的第一个实参的语法形式

## 关键设计决策

1. **Pattern 复用 Expr 字面量形状**：`Pattern::Array` / `Pattern::Dict`
   与 `Expr::Array` / `Expr::Dict` 同构（连 Span 都带），但叶子分歧：
   - `Pattern::Ident(String, Span)` 绑定新名字
   - `Pattern::Wildcard(Span)` 匹配任何值，不绑定
   - `Pattern::Literal(Literal, Span)` 用于 §7.6 MATCH（v0.4 暂不实现
     字面量解构，但 AST 已就位以便 MATCH 复用）
2. **`Expr::Let` 兼容路径**：`parse_let` peek 第一个 token，Ident 进
   旧路径，保留 `Expr::Let`；`[` / `Ident + 注解` 进新路径 `Expr::LetPattern`。
   这样 500+ 旧测试和下游消费者对 `Expr::Let` 的模式匹配全部不破。
3. **错误码**：新增 E0025（shadow builtin，本批同发但留 A5 触发）、
   E0026（destructure pattern mismatch）、E0027（MATCH fallthrough，本批同
   发但 A4 触发）。wlwl-error 升级 schema 计数 36→39。
4. **dict pattern 键类型**：仅接受 Literal（StringLit / True / False
   / Null）；Wildcard / Array / Dict 作键报 E0010。Integer / Float
   键因 lexer 的 TokenKind 没携带数值，spec 要求 literal 所以 v0.4
   暂不接；MATCH（A4）会一起处理。
5. **错误分类**：
   - E0026 = 解构形状不匹配（长度不足 / 字典缺键 / 字面量不等）
   - E0030 = 解构时值的运行时类型不对（如 INTEGER 套数组 pattern）
   - E0024 / E0010 留给解析阶段

## 行为变更（用户可见）

| 输入 | 旧行为 | 新行为 |
|---|---|---|
| `LET([a, b], [1, 2]); +(a, b);` | E0020 undefined name `a` | `3` |
| `LET([head, *rest], [10, 20, 30, 40]); head;` | E0020 | `10` |
| `LET([head, *rest], [10, 20, 30, 40]); rest;` | E0020 | `[20, 30, 40]` |
| `LET(["x": x, "y": y], ["x": 100, "y": 200]); +(x, y);` | E0020 | `300` |
| `LET([_, mid, _], [1, 2, 3]); mid;` | E0020 | `2` |
| `LET([a, b], [1]);` | E0020 | E0026 destructure pattern mismatch |
| `LET(["x": x], ["y": 1]);` | E0020 | E0026 destructure pattern mismatch |
| `LET([a, b], 42);` | E0020 | E0030 type error (expected ARRAY) |
| `LET([[a, b], [c, d]], [[1, 2], [3, 4]]);` | E0020 | `10` |
| `LET(x, 42); x;` | `42`（Expr::Let） | `42`（仍 Expr::Let，零行为变化） |
| `LET(x: INTEGER, 1);` | `1`（Expr::Let 带注解） | `1`（仍 Expr::Let，零行为变化） |
