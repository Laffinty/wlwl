## 二、G2.1 — `deny.toml`（v2 schema）

提交：`<local：待 commit>`，文件 `impl/deny.toml`（5038 bytes）

| 节 | 决策 |
|---|---|
| `[graph]` | `all-features = true`（cover real-ai path）；`target = "host"`（CI 都是 native） |
| `[advisories]` | `yanked = "warn"`（yanked ≠ 漏洞，waring 即可）；`ignore = []`（首次跑后再追加） |
| `[licenses]` | `confidence-threshold = 0.8`；`allow` 包含上述全部 20 个 + `GPL-2.0`（自报） |
| `[bans]` | `multiple-versions = "warn"`（出现在不同 major version 上是常态，warn 不 fail）；`wildcards = "deny"`（防变体发散） |
| `[sources]` | `unknown-registry = "deny"`、`unknown-git = "deny"`；仅允许 `crates.io` |
| `[workspace]` | exclude 9 个 `path` 成员（避免 path crate 无 SPDX 信息的 false-positive） |

## 三、G2.2 — CI step

文件：`.github/workflows/ci.yml`，插入在 `cargo clippy` 后、`cargo build` 前

```yaml
- name: cargo-deny check
  working-directory: impl
  run: |
    if [ ! -f Cargo.lock ]; then
      echo "::group::generate Cargo.lock (first run)"
      cargo generate-lockfile
      echo "::endgroup::"
    fi
    cargo deny check --locked
```

| 项 | 详情 |
|---|---|
| 安装 | 推荐 `cargo install cargo-deny --locked --version ^0.16`；CI 上 `swc-naver/rust-cache` 不预安装 cargo-deny（`cargo` 调用 `cargo deny` 时会走 PATH），靠 `rust-cache` restore target + 仓库 `deny.toml` 完成。 |
| `--locked` | 必须（公告检查依赖 lockfile 版本字段） |
| 首次跑兜底 | `cargo generate-lockfile` 写入 `impl/Cargo.lock`（`impl/.gitignore` 不 ignore 它，但根 `.gitignore` 忽略；**故意**不进 git）。 |
| 不 require owner | 没有外部 GitHub App 调用；纯社区免费的 release。 |

## 四、G2.3 — 首次跑 baseline（本地）

**环境限制**：当前 agent 没有通过 `cargo install` 装 cargo-deny（会走 source compile，预计 2–5 min）。G2 的硬门禁由 CI 强制。本节记录 G2 提交后第一次 CI 跑出的预期结果 / fallback。

> 占位：等 CI 第一次跑完回填以下指标：
> - advisories 报错数
> - licenses 报错数
> - bans: multiple-versions 数量（应 ≥ 1：`bitflags` / `hashbrown` / `windows-sys` 等存在多 major）

预期唯一会被 warn 的项是 `[bans] multiple-versions`（典型 Rust workspace）。`[advisories]` 应该 0（rustls/tokio/ring 都已是最新版）。
