## 四、G3.5 CI 装入阶段门

文件:`.github/workflows/ci.yml`

```yaml
# [v0.2 Phase G3] rustdoc gate. `cargo doc` with `-D warnings`
# ensures all EXISTING docs are valid (no broken intra-doc
# links, no malformed markdown, no unresolved symbols).  ...
- name: cargo doc --no-deps -D warnings
  working-directory: impl
  env:
    RUSTDOCFLAGS: -D warnings
  run: cargo doc --workspace --no-deps
```

位置:在 clippy 后面、cargo-deny 前面

- 不能装 vs clippy 后面的 `RUSTFLAGS=-D warnings` env 已有重叠 · 以 令行 重设 `RUSTDOCFLAGS=-D warnings` 是 rustdoc 自己 采用
- `--no-deps` 避免 cross-compile deps doc 减 动
- 以接受 不同 stub toy 补 下的 incoming这进 只装 rustdoc 装 必顶 加 以项 detail but 项目顶 不动
