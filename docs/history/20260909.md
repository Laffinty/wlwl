## 范围 (spec v0.4 §7.6)

`MATCH(scrutinee, [clauses], default?)` 宏函数(special-form):

- **Pattern 形态**(与 A3 共用):
  - `Pattern::Ident(name, span)` — 绑定新名字
  - `Pattern::Wildcard(span)` — 匹配任意值
  - `Pattern::Literal(Literal, span)` — 字面量匹配(§7.6)
  - `Pattern::Array(elements, rest, span)` — 数组,可带 `*rest` 剩余
  - `Pattern::Dict(entries, span)` — 字典(仅 Literal 键)
  - `Pattern::Constructor(name, args, span)` — 构造器(`OK(x)` / `ERR(e)`)
- **clauses**:有序列表,首匹配胜出
- **default**:可省,省略时合成 `Expr::Literal(Null, ...)`(spec §7.6 line 879
  优于 line 878——采纳 879 路径,见"设计决策"段)
- **无匹配无 default** → E0027(spec 末段;本批不触发路径)

## 关键设计决策

1. **spec §7.6 line 878 vs 879 矛盾**:line 878 说"无 default → E0027";
   line 879 说"default 可省略"。本批**采纳 879**,parser 在 `MATCH(v, [...])`
   省略 default 时合成 `Expr::Literal(Null, ...)`;eval_match 永远走 default
   路径。`match_fell_through` helper 标 `#[allow(dead_code)]` + 独立 E0027
   unit test 覆盖,等 spec v0.5 决定是否启用严格路径。
2. **TokenKind::Match 作为 lexer-level keyword**:与 OK / ERR / IS_OK 一致的
   v0.1 风格,parser 走 special-form 分发;v0.1 baseline 14 个 §3.3 关键字
   列表不动。
3. **Pattern::Constructor 当前只支持 OK / ERR**:parser 写死
   (`parse_pattern_constructor` 看到 Ok/Err 才走 Constructor),eval 加
   defend-in-depth 拒绝其他 ctor name。其他 ctor(SOME / NONE 等)留 v0.5。
4. **Pattern AST 与 A3 解构完全共用**(`Pattern::Ident / Wildcard / Literal /
   Array / Dict`),A4 新增 `Pattern::Constructor` 一个 variant。wlwl-ast 升级
   一处,w-parser 加一个 arm,w-eval 加一处构造器分支。
5. **错误码 E0027** 注册到 schema 1.1.0 但本批不触发;与 A3 E0026 同名空间。

## 实现摘要

### wlwl-error
- `E0027` 注册(match fell through,本批占位不触发),`as_str` /
  `category` / `snap_name` 同步;schema 计数 39 保持(A3 已注册 E0027)。

### wlwl-ast
- 新 `Pattern::Constructor { name, args, span }` 一个 variant。
- 既有 5 个 variant(Ident / Wildcard / Literal / Array / Dict)与 A3 共用。

### wlwl-parser
- 新 `parse_match` / `parse_pattern_constructor` / `parse_match_clauses`。
- `parse_primary` 新增 `TokenKind::Match` arm。

### wlwl-eval
- 新 `eval_match` 函数,首匹配胜出,default 永远走(per 设计决策 1)。
- `Pattern::Constructor` 分发:仅 `OK` / `ERR` 接受,其他 ctor name → E0030。
- `destructure` 复用 A3 函数,数组 / 字典模式直接走 destructure 路径。
- `match_fell_through` helper 标 `#[allow(dead_code)]` 备用。

## 行为变更(用户可见)

| 输入 | 旧行为 | 新行为 |
|---|---|---|
| `MATCH(OK(1), [OK:((x), x)], NULL);` | E0020 undefined `MATCH` | `1` |
| `MATCH(ERR("e"), [ERR:((x), x), OK:((x), x)], -1);` | E0020 | `"e"` |
| `MATCH([1, 2], [[a, b]: +(a, b)], -1);` | E0020 | `3` |
| `MATCH([1, 2, 3, 4], [[head, *rest]: head], -1);` | E0020 | `1` |
| `MATCH(42, [], NULL);` | E0020 | `NULL`(默认走 NULL 分支) |
| `MATCH(OK(1), [OK:((x), x)]);`(无 default) | E0020 | `1`(合成 default=NULL 但 OK 分支已匹配) |
